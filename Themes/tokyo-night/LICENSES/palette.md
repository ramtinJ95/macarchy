# Omarchy Tokyo Night palette

Macarchy's Tokyo Night semantic and terminal colors are resolved from
Omarchy's `themes/tokyo-night/colors.toml` using Macarchy's documented Omarchy
palette conversion. The source is byte-identical at both the M5 compatibility
baseline and the current parity revision:

- Compatibility baseline: `9285b19d6a72eba3df8537d62a4cd5506a803d89`
- Parity revision: `0b3f1b7ead00ac4bcbaae8bac16bab3f7efbe516`
- Source: <https://github.com/basecamp/omarchy/blob/0b3f1b7ead00ac4bcbaae8bac16bab3f7efbe516/themes/tokyo-night/colors.toml>
- License: MIT; see Omarchy's root `LICENSE`

The package keeps its stable Macarchy identifier and named-consumer mappings;
all canonical palette values match the Omarchy conversion.
